Open questions for v3

  1. Is the still clock the right mark for a queued message, or should it be the session's own "queued" mark, the turning arc with the blue centre? The arc moves, and a waiting message doesn't run, so this page uses the still clock.

  5. After Esc, Esc, should the text that came back from the queue be marked in the box, for example as a selection, so one key can drop it?
  6. Can you edit or take back a single queued message, for example with the box's up arrow, as the CLI does?
